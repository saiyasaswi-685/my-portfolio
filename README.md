- Responsive Design
- Modern UI
- Smooth Animations
- Framer Motion Effects
- Projects Showcase
- Skills Section
- Contact Section
- GitHub & LinkedIn Links

## Installation

Clone the repository:

```bash
git clone https://github.com/saiyasaswi-685/my-portfolio.git
````

Go to project folder:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```
